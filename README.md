# 📈 Power BI Sales Dashboard (Excel Data)

This project showcases a **modern and interactive Power BI dashboard** developed using Excel/CSV datasets.  
The dashboard provides meaningful insights by visualizing **profit trends**, **category-wise quantity**, **customer-level amounts**, **sub-category performance**, and **monthly variations**.

---

## 🚀 Project Overview

The goal of this project is to transform raw order and sales data into an insightful **business intelligence dashboard**.  
It helps stakeholders quickly understand:

- Which products generate the highest profit  
- Customer spending patterns  
- Which payment modes are used most  
- Monthly profit fluctuations  
- Category-wise quantity and amount distribution  

The dashboard uses smooth gradients, clean UI, and interactive visual filters.
